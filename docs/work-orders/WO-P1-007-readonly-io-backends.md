## Goal + Acceptance criteria

Provide concrete read-only backends for the injected observer interfaces without creating a generic shell execution capability.

Acceptance:
- tests written before implementation;
- PowerShell backend accepts only the exact process/port inspection command shapes generated by `WindowsRuntimeObserver`;
- arbitrary or mutating PowerShell scripts are rejected before execution;
- subprocess execution uses `shell=False`, captured output, bounded timeout, and explicit UTF-8 output handling;
- HTTP backend accepts only `http://` loopback targets with exact `/readyz` path and no credentials/query/fragment;
- HTTP 200 -> READY; explicit HTTP error -> NOT_READY; transport failure -> NOT_READY/UNKNOWN with safe error code and no secret echo;
- unit tests mock all subprocess/network calls;
- no lifecycle mutation commands exist;
- full tests, compileall, mutation scan, and `git diff --check` pass.

## Forbidden

- No target process start/stop/kill/restart.
- No generic arbitrary PowerShell execution.
- No file deletion/write or runtime-profile mutation.
- No credential/tunnel secret access.
- No non-loopback HTTP.
- No A-Wiki/Phase6 mutation.
- No Git remote/push.
