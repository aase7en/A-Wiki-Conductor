## Deliverables

1. **NEW `route_telemetry_projection.py`** (pure, no clock/network/store I/O): compose per-attempt route telemetry from injected inputs — (a) optional selection result (CandidateEvaluation-shaped) → shortlist + per-candidate reason codes + expected_configuration_generation; (b) optional semantic telemetry rows; (c) execution/receipt row objects. Output a frozen `RouteTelemetryEvidence` carrying: attempt identity (execution_id/attempt_id; optional request_id), selection summary, measured tokens/latency (monotonic where available, wall-stamps labeled as wall), receipt linkage, and TYPED cost semantics — absent pricing/currency/usage ⇒ `cost: {"state": "UNKNOWN", "reason": ...}`, never 0/None-as-zero. 4. **Tests** (new + extended): axes — duplicate identity dedup w/ duplicate_of; fallback/retry chains; attempted-vs-accepted; absent usage/currency/pricing → UNKNOWN (not 0); wall-vs-monotonic labeled distinctly; evidence-unavailable degradation (telemetry fails, nothing else changes); observability absent-input byte-identity; telemetry correlation fields default-None pass-through; baseline route output unchanged (selection function itself untouched — prove via existing pinned suite green).
