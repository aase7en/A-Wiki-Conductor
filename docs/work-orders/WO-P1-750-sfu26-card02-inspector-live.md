## Design Contract

1. **New module `monitor_live_provider.py`** (pure, no clock/network/subprocess): factory `build_live_monitor_provider(env=None, ...)` returning a zero-arg `provider() -> dict` closure that:
   - reads knobs from injectable env mapping (default `os.environ`) following the `agent_change_packets.py:652` / `awiki_environment_resolver.py:52` precedent: `A_CONDUCTOR_AWIKI_ROOT` (skills registry root override; UNSET = collector default preserved verbatim — Windows behavior unchanged), `A_CONDUCTOR_MONITOR_PROJECTION` (`off` = kill-switch);
   - composes the three existing collectors (`collect_local_tool_rows` instances_root from existing default, `collect_local_hook_rows` repo_root, `collect_local_skill_rows` awiki_root/max_age) and `monitor_projection.build_monitor_views`, passing through their typed failures;
   - returns `{"mode": "off", "monitor": <exact current placeholder dict>}` when kill-switch active; on collector/projection failure returns a TYPED error child (distinct from both `off` and healthy) that names the failing section without embedding raw exception strings or paths.
2. **web_api wiring**: `create_app` constructs the live monitor provider ONCE (no I/O at import or construction — first collection happens inside the feed lifecycle), attaches it to the feed/`app.state`. Collection cadence rides the EXISTING `MonitorApiServer`/`WebFeed` poller (one shared producer); HTTP snapshot handlers only read the last collected result — never call collectors in the request path. First request before first poll completes yields a typed not-yet-collected marker, not empty success.
3. **Snapshot DTO**: the `monitor` child at `web_api.py:166` becomes: kill-switch off → EXACT current placeholder verbatim; live healthy → sanitized monitor views (existing projection redaction/bounds unchanged); live failing → typed error child with sibling lanes INTACT (removal of sibling data on monitor failure is forbidden).
4. **Client compatibility gate**: BEFORE finalizing the DTO, the implementer must check `web/sunday-family/src/api.ts` snapshot validator behavior against a live-views monitor child (read-only; no web/ edits in this lane). If the validator would REJECT live monitor views, STOP and report for claim amendment — do not silently weaken the validator or ship a shape the client drops.
