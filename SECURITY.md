# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please:

1. **Do not** open a public GitHub issue
2. Use GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-reviewing/privately-reporting-to-a-repository)
3. Or contact the repository owner directly via GitHub

## Scope

- The desktop application code (`src/a_conductor/`)
- The installer (`scripts/installer_main.py`)
- Connector instance management

## Out of Scope

- The Serena engine itself (report to https://github.com/oraios/serena)
- OpenAI tunnel infrastructure (report to OpenAI)
- Your own project code managed by connectors
